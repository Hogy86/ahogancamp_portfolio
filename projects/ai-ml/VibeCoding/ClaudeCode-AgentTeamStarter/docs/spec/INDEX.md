## How to use it

1. Find the IDs your change touches in the table below.
2. If `docs/spec/features/<ID>.md` exists, it is the current text; read it.
3. Otherwise open the file and section in "Defined in", then each file in
   "Changed by". Use `grep -n "<ID>" <file>` to jump to the lines.
