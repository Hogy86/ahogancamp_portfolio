# Change specs

One file per change after the first version, named `vN-short-name.md`
(for example `v3-boss-speed.md`). Each one says what changes, the
acceptance criteria with IDs, which features it touches, and the owner
decisions behind it. Aim for about 5 KB; a change that needs much more is
probably a large change.

Change specs are never rewritten. A later change that alters the same
feature gets its own file and says which earlier text it replaces.
